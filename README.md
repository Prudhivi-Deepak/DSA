⭐ Recommended “Top Core 50” (If you want the fastest teaching ROI)
If you want your viewers to become productive quickly, prioritize these:
I/O: read_csv, to_csv, read_excel
Inspect: head, info, describe, value_counts
Indexing: loc, iloc, query, isin
Clean: dropna, fillna, replace, drop_duplicates, astype, to_datetime
Transform: assign, apply, map, cut, qcut, get_dummies
Groupby: groupby, agg, transform, pivot_table
Join: merge, concat
Reshape: melt, pivot, stack/unstack, explode
Time: resample, rolling
Text: str.contains, str.replace, str.split, str.extract
Stats: corr, quantile
